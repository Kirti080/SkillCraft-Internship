# 💼 SkillCraft Technology Internship Projects

This repository contains all four web development tasks completed as part of my internship at **SkillCraft Technology**. Each task showcases different web development concepts like DOM manipulation, event handling, responsiveness, interactivity, and frontend design.

---

## 🌐 Task 1: Landing Page

**Description:**  
A responsive, animated landing page for SkillCraft Technology showcasing their brand and services with a fixed navigation bar, dark theme, and glowing accents.

**Features:**
- Dark theme with glowing highlights
- Fixed navigation menu
- Responsive design
- Scroll-friendly layout with section placeholders

📁 Files: `index.html`, `style.css`

---

## 🧮 Task 2: Calculator Web App

**Description:**  
A fully functional calculator built to demonstrate DOM manipulation and event handling with arithmetic operations. Includes keyboard support and error handling.

**Features:**
- Add, subtract, multiply, divide
- Clear and equals functions
- Keyboard input support
- Error handling
- Fixed top navigation

📁 Files: `index.html`, `style.css`, `script.js`

---

## 🤪 Task 3: Interactive Quiz Game (Funny Version)

**Description:**  
A fun, interactive multiple-choice quiz game with various question types (single select, multiple select, fill-in-the-blanks) designed to be playful and engaging.

**Features:**
- Three unique question types
- Score display at the end
- Funny text and emojis
- Styled for humor + responsiveness

📁 Files: `index.html`, `style.css`, `script.js`

---

## ✅ Task 4: To-Do Web App

**Description:**  
A simple and clean To-Do web app that allows users to add, edit, delete, and complete tasks. Users can also set date and time for each task.

**Features:**
- Add/edit/delete tasks
- Mark tasks as complete
- Store date & time for each task
- Responsive dark UI with fixed navbar

📁 Files: `index.html`, `style.css`, `script.js`
